Análisis estadístico aplicado a la regulación de pozos en el estado de Nueva York

Misión y Visión

Los pilares que guían el desarrollo de este proyecto estadístico.

01

Misión

Aplicar métodos estadísticos rigurosos para identificar y cuantificar los factores que explican la regulación, distribución y evolución histórica de los pozos de petróleo, gas y otros tipos en el estado de Nueva York.

02

Visión

Convertirnos en una referencia académica para el análisis estadístico de información energética histórica, revelando tendencias reales y el potencial de los datos como herramienta para la toma de decisiones informadas.

Motivación del proyecto

FIGEMPA
Universidad Central del Ecuador

¿Por qué este proyecto?

Como estudiantes de la Universidad Central del Ecuador, desarrollamos este proyecto con el propósito de aplicar la estadística como herramienta fundamental en el análisis de datos del mundo real.

Nuestro objetivo no es solo interpretar la información, sino también destacar la relevancia de la estadística en la toma de decisiones informadas dentro del ámbito profesional relacionado con nuestra carrera en geología, minas, petróleos y ambiental.

Introducción

Contexto, ubicación geográfica y objetivos del proyecto.

01 · Contexto

Planteamiento del problema

El análisis de la industria de los hidrocarburos permite comprender la evolución y comportamiento de la actividad de extracción a través del tiempo. Mediante el estudio de variables como ubicación, profundidad y estado operativo de los pozos, es posible identificar tendencias y patrones útiles para futuras investigaciones

Como caso de estudio, se empleará la base histórica de pozos de hidrocarburos del estado de Nueva York, con registros desde 1860

02 · Dirección

Objetivo general

Aplicar la estadística para examinar los pozos regulados de petróleo, gas y otros tipos en el estado de Nueva York desde 1860, mediante herramientas computacionales, con el fin de identificar su distribución, evolución temporal y características principales.

03 · Desarrollo

Objetivos específicos

  • Conocer la situación de los pozos regulados de petróleo, gas y otros tipos en el estado de Nueva York a través de sus características más importantes y medidas estadísticas.
  • Emplear un modelo de probabilidad para establecer conclusiones sobre los pozos regulados en el estado de Nueva York a partir de los resultados obtenidos de una muestra del conjunto de datos.
  • Deducir relaciones entre variables de los pozos regulados en el estado de Nueva York con el fin de realizar estimaciones y analizar tendencias a lo largo del tiempo.

Modelo de Deep Learning

Redes Neuronales Artificiales

01 · Planteamiento

Planteamiento del problema

En la industria petrolera, estimar la profundidad de los pozos es un reto por la no linealidad y el desbalance en los datos históricos. Para superar estas limitaciones, se utiliza Machine Learning mediante redes neuronales profundas y perceptrones multicapa procesando variables geográficas y temporales clave. Este enfoque permite optimizar la planificación técnica y mejorar la precisión en las estimaciones.

02 · Propósito

Objetivos

Desarrollar e implementar modelos de redes neuronales profundas (tanto de clasificación como de regresión) basados en variables de entrada como la latitud, la longitud, la elevación y el año de terminación, para predecir y clasificar de forma precisa la profundidad vertical real (True Vertical Depth) en pozos petroleros.

03 · Resultados

Conclusiones

El uso de redes neuronales profundas permitió procesar datos históricos masivos de pozos y capturar relaciones no lineales complejas. Asimismo, se logró resolver el desbalance de clases de forma efectiva, mientras que las estrategias de regularización aseguraron un alto nivel de generalización sin sobreajuste, permitiendo finalmente integrar herramientas interactivas para consultas en tiempo real y optimizar la toma de decisiones técnicas.

Prompt REDES NEURONALES

Instrucción diseñada para generar un modelo avanzado de Machine Learning y su respectiva interfaz interactiva.

> Eres un experto senior en Machine Learning e Ingeniería de Petróleos. Necesito que desarrolles un script completo en Python (utilizando librerías como Pandas, Scikit-Learn y TensorFlow/Keras) para construir un modelo de Red Neuronal Artificial (ANN).
> El script debe contemplar dos enfoques basados en el dataset histórico:
  • 1. Modelo de Clasificación: Para agrupar y clasificar la profundidad del pozo en categorías (BAJA, MEDIA, ALTA).
  • 2. Modelo de Regresión: Para predecir el valor continuo de la profundidad.
> Utiliza estrictamente las siguientes variables específicas del dataset:
  • • Variables de Entrada / Predictoras (X): Surface Latitude (Latitud de superficie), Surface Longitude (Longitud de superficie), Elevation, ft (Elevación en pies sobre el nivel del mar) y Completion Year (Año de terminación u operación).
  • • Variable de Salida / Objetivo (Y): True Vertical Depth, ft (Profundidad Vertical Real en pies / TVD).
> Organiza estrictamente el código por secciones utilizando comentarios claros de Markdown o separadores en el siguiente orden lógico:
  • 1. Librerías
  • 2. Carga de Dataset
  • 3. Procesamiento y Limpieza de datos
  • 4. División de Datos
  • 5. Modelo
  • 6. Entrenamiento
  • 7. Evaluación
  • 8. Gráficas del Modelo
  • 9. Predicción
  • 10. Interfaz Gráfica / Aplicación (Creación de una aplicación interactiva web simple en Python utilizando Streamlit o Gradio basada en el modelo entrenado para ingresar las 4 variables de entrada y visualizar la profundidad estimada de forma visual).

Modelo de Ensamble

Random Forest

01 · Planteamiento

Planteamiento del Problema

En la industria petrolera, la perforación de pozos requiere estimar la profundidad con precisión para optimizar las operaciones. Sin embargo, los métodos convencionales enfrentan desafíos al analizar grandes volúmenes de datos históricos debido a su alta no linealidad y complejidad estructural.

Para resolver estas incertidumbres técnicas, el uso de Machine Learning —específicamente algoritmos basados en árboles de decisión— permite procesar múltiples variables geológicas, geográficas y operativas clave para predecir de forma confiable la profundidad de los pozos.

Mediante la implementación de un modelo de Random Forest, este enfoque busca optimizar la planificación técnica y mejorar la precisión en la estimación de profundidades.

02 · Propósito

Objetivo

Desarrollar e implementar un modelo de aprendizaje supervisado mediante el algoritmo Random Forest, utilizando variables geológicas y operativas, para predecir con alta precisión la profundidad vertical real (True Vertical Depth) en pozos petroleros.

03 · Resultados

Conclusiones

El uso del modelo Random Forest permitió procesar datos históricos masivos de pozos y capturar relaciones no lineales complejas entre las variables geológicas y operativas. Asimismo, se logró un alto nivel de ajuste predictivo sin sobreajuste, validado mediante métricas de desempeño robustas, permitiendo identificar las variables de mayor impacto en la estimación para optimizar la toma de decisiones técnicas en la industria petrolera.
